# PRIYASA storefront reference

The storefront is designed to follow the supplied PRIYASA WooCommerce reference: editorial hero, collection merchandising cards, affiliate promotion, flash-sale product rail, new-launch rail, trust/delivery strip, festival edit, best sellers and category discovery.

All product data remains database-driven. Promotional imagery and CMS-managed sections can replace the fallback merchandising presentation without changing checkout, cart, authentication, payment or order APIs.
